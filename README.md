# TaskFlow - Task Management App 🎯

A full-stack task management application built with React, Node.js, and MongoDB to help you organize and manage your daily tasks efficiently.

**Live Demo:** [https://taskflow.vercel.app](https://taskflow.vercel.app)

---

## ✨ Features

- 👤 **User Authentication** - Secure login and signup with JWT
- ✅ **Create Tasks** - Quickly add new tasks to your list
- ✏️ **Edit Tasks** - Update task details anytime
- 🗑️ **Delete Tasks** - Remove completed or unwanted tasks
- 🏷️ **Categories** - Organize tasks by different categories
- ⚡ **Priority Levels** - Mark tasks as High, Medium, or Low priority
- 📅 **Due Dates** - Set deadlines and get reminded
- ✔️ **Mark Complete** - Check off completed tasks
- 🔍 **Search & Filter** - Find tasks easily
- 🌙 **Dark/Light Mode** - Toggle between themes
- 📱 **Fully Responsive** - Works on mobile, tablet, and desktop

## 📖 How to Use

1. **Sign Up** - Create a new account with email and password
2. **Login** - Enter your credentials to access your tasks
3. **Create Task** - Click the "Add Task" button
4. **Fill Details:**
   - Task title
   - Description
   - Category
   - Priority level
   - Due date
5. **Submit** - Click "Create" to add task
6. **Manage Tasks:**
   - Check box to mark complete
   - Click edit to modify
   - Click delete to remove
7. **Search** - Use search bar to find specific tasks
8. **Filter** - Filter by category or priority
